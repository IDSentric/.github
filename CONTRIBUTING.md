# Contributing to IDSentric

Thank you for your interest in IDSentric!

## Reporting Issues

For security vulnerabilities, please follow our [security policy](SECURITY.md).

For general questions, support requests, or feedback, please contact us through our official website: https://www.idsentric.com

## Code Contributions

We welcome community contributions. Before opening a pull request:

1. Open an issue to discuss the change you'd like to make.
2. Ensure your changes align with the project's goals and scope.
3. Follow existing code style and conventions.

## Code of Conduct

Be respectful and considerate in all interactions.
