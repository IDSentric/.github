# Security Policy

## Supported Versions

We encourage responsible disclosure of security vulnerabilities.

## Reporting a Vulnerability

**Do not report security vulnerabilities in public GitHub issues.**

For confidential security reports, contact the organization through its official channels at:

- **Website**: https://www.idsentric.com

For more information, see our [Privacy Policy](https://www.idsentric.com/privacy) and [Terms of Service](https://www.idsentric.com/terms).

## Security Features

We take security seriously. If you have suggestions for improving our security posture, feel free to open a discussion or contact us through the official website.
